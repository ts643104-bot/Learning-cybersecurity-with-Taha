# تعليم الأمن السيبراني مع طه

موقع تعليمي تفاعلي باللهجة المصرية، بإشراف المهندس طه سلطان، لتعلّم أساسيات الكمبيوتر ولينكس والأمن السيبراني من البداية وحتى مستوى متوسط.

## تشغيل الموقع

افتح `index.html` في متصفح حديث. الموقع ثابت ولا يحتاج إلى تثبيت حزم أو خادم.

## المحتوى

- مسارات قصيرة ودروس واختبارات تفاعلية.
- خريطة تقدّم، إنجازات، وبطاقات لمراجعة المصطلحات.
- محاكي لينكس ومختبرات ببيانات افتراضية محلية.
- سيناريو تدريبي لاكتشاف التصيّد وخطوات دفاعية للتعامل مع الاشتباه في اختراق.
- حفظ التقدّم محليًا في المتصفح، من غير حساب.

## السلامة

المختبرات محاكاة تعليمية فقط، ولا تتصل بأجهزة أو مواقع أو شبكات حقيقية. لا تختبر نظامًا لا تملكه دون إذن صريح. لا يُعد الموقع بديلًا عن فريق الدعم أو استجابة الحوادث المختص.

## النشر على Vercel

المشروع تطبيق ويب ثابت (HTML/CSS/JavaScript)، ومجهز للنشر على Vercel من غير build أو تثبيت حزم.

1. سجّل الدخول إلى [Vercel](https://vercel.com/) واختر **Add New → Project**.
2. استورد المستودع `ts643104-bot/Learning-cybersecurity-with-Taha` من GitHub.
3. اختار **Other** كإطار العمل (Framework Preset)، وسيب أمر البناء فاضي.
4. خلي **Output Directory** على `.`، ثم اضغط **Deploy**.
5. بعد نجاح النشر، هتلاقي رابط الموقع في لوحة المشروع على Vercel. كل تحديث على فرع `main` هيبدأ نشر جديد تلقائيًا.

ملف `vercel.json` يحدد ملفات الموقع كرزمة ثابتة ويضيف ترويسات أمان أساسية.

## النشر على GitHub Pages

1. ارفع ملفات المشروع إلى مستودع GitHub.
2. افتح **Settings → Pages**.
3. اختر **Deploy from a branch**، ثم فرع `main` ومجلد `/ (root)`، واضغط **Save**.
4. بعد اكتمال النشر، سيظهر رابط الموقع في صفحة Pages.

الموقع يستخدم مسارات نسبية للملفات، لذلك يمكن نشره من الجذر أو من مجلد مشروع GitHub Pages.
