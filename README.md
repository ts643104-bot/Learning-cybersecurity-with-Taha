# تعليم الأمن السيبراني مع طه

منصة تعليمية تفاعلية باللهجة المصرية، بإشراف المهندس طه سلطان، بمنهج هندسي متدرج للمبتدئين من أساسيات الكمبيوتر وحتى المشاريع الدفاعية.

## تشغيل الموقع

افتح `index.html` في متصفح حديث. الموقع ثابت ولا يحتاج إلى تثبيت حزم أو خادم.

## المحتوى

- منهج من ٨ مراحل و٣٥ درسًا متدرجًا؛ يبدأ من الأساسيات وينتهي بثمانية تحديات صعبة تربط المفاهيم بمواقف عمل ومحاكاة. كل درس فيه فكرة أساسية ومثال عملي ونقطة تحذير، وصور SVG تعليمية، وشخصية متحركة، وتسجيلات صوتية منفصلة، وتمرين واختبار قصير:
  1. أساسيات الكمبيوتر والإنترنت: نظام التشغيل والملفات والويب.
  2. لينكس وسطر الأوامر: التنقل والملفات والصلاحيات.
  3. الشبكات: IP وDNS وHTTP/HTTPS والجدران النارية.
  4. أساسيات البرمجة بـ Python: البيانات والشروط والدوال.
  5. مبادئ الأمن السيبراني: المخاطر والحسابات والتصيد والتشفير.
  6. أمن الويب: الحقن وXSS والصلاحيات والجلسات وطرق الوقاية.
  7. التحليل والاستجابة للحوادث: السجلات والتنبيهات وحفظ الأدلة.
  8. مشاريع ومراجعة نهائية: مراجعة تطبيق تدريبي وسيناريو دفاعي.
- خريطة تقدّم تفاعلية، إنجازات، وبطاقات لمراجعة المصطلحات.
- محاكي لينكس ومختبرات ببيانات افتراضية محلية.
- محاكاة فريق دفاع (Blue Team) فيها سجل أحداث وهمي، قرارات استجابة متعددة المراحل، ونتيجة محفوظة محليًا.
- سيناريو تدريبي لاكتشاف التصيّد وخطوات دفاعية للتعامل مع الاشتباه في اختراق.
- صفحة الأدوات تبدأ بمتطلبات الكمبيوتر والشبكات وتحديد النطاق، ثم مسار Python من الصفر بأمثلة ونواتج متوقعة وتمارين، ومداخل آمنة لـ Bash وHTML/CSS/JavaScript وSQL.
- حفظ التقدّم محليًا في المتصفح، من غير حساب.
- ترحيل تلقائي لتقدم المتعلمين المحفوظ من نسخة المنهج السابقة.

## السلامة

المختبرات محاكاة تعليمية تحاكي سير الشغل ومخرجاته ببيانات وسجلات مصطنعة؛ لا تستخدم بيئة أو حسابات حقيقية، ولا تتصل بأجهزة أو مواقع أو شبكات خارجية. الشرح دفاعي ولا يعرض حادثة حقيقية بعينها. الدروس متاحة حاليًا كنصوص؛ تم إيقاف الملفات الصوتية مؤقتًا إلى أن تُضاف تسجيلات بشرية أصلية.

المحتوى للتعليم والدفاع ولا يمنح إذنًا لاختبار أي نظام. قبل فتح المنصة، يؤكد المتعلم فهمه لهذه القواعد وموافقته على استخدامها بشكل مسؤول؛ ويظهر التذكير أيضًا في تذييل كل صفحة. منشئ المحتوى لا يوافق على الاستخدام المخالف ولا يشجّعه، وكل مستخدم مسؤول عن أفعاله. مخالفة القانون قد تؤدي للمساءلة وعقوبات تصل للحبس حسب قانون البلد. استأذن كتابةً، التزم بالنطاق، حافظ على الأدلة، واستخدم المعرفة للخير. الموقع لا يغني عن فريق الدعم أو الاستجابة للحوادث المختص.

## النشر على Vercel

المشروع تطبيق ويب ثابت (HTML/CSS/JavaScript)، ومجهز للنشر على Vercel من غير build أو تثبيت حزم.

1. سجّل الدخول إلى [Vercel](https://vercel.com/) واختر **Add New → Project**.
2. استورد المستودع `ts643104-bot/Learning-cybersecurity-with-Taha` من GitHub.
3. اختار **Other** كإطار العمل (Framework Preset)، وسيب أمر البناء فاضي.
4. خلي **Output Directory** على `.`، ثم اضغط **Deploy**.
5. بعد نجاح النشر، هتلاقي رابط الموقع في لوحة المشروع على Vercel. كل تحديث على فرع `main` هيبدأ نشر جديد تلقائيًا.

ملف `vercel.json` يحدد ملفات الموقع كرزمة ثابتة ويضيف ترويسات أمان أساسية.

## النشر على GitHub Pages

1. ارفع ملفات المشروع إلى مستودع GitHub.
2. افتح **Settings → Pages**.
3. اختر **Deploy from a branch**، ثم فرع `main` ومجلد `/ (root)`، واضغط **Save**.
4. بعد اكتمال النشر، سيظهر رابط الموقع في صفحة Pages.

الموقع يستخدم مسارات نسبية للملفات، لذلك يمكن نشره من الجذر أو من مجلد مشروع GitHub Pages.
